How to Upload Assignments to GitHub Pages

Easy workflow to add assignments and publish them online

💡 HOW THIS PORTFOLIO WORKS: 1. Click "+ Add Assignment" on this page to add your assignment cards.
2. Click "Save HTML for GitHub" in the top bar. It will download an updated index.html file with all your assignments permanently saved inside the code!
3. Upload that index.html (along with your assignment files) to your GitHub repository.

Recommended GitHub Repository Structure

your-github-repo/
├── index.html                  <-- This portfolio file
└── assignments/                <-- Create this folder for your work
    ├── assignment1/
    │   └── index.html          <-- Link as: ./assignments/assignment1/index.html
    ├── assignment2.pdf         <-- Link as: ./assignments/assignment2.pdf
    └── lab1.zip                <-- Link as: ./assignments/lab1.zip

How to Enable Free GitHub Pages

  1. Create a public repository on GitHub and upload your index.html file.
  2. Go to your repository Settings → Pages (on the left sidebar).
  3. Under Branch, select main and / (root), then click Save.
  4. Wait 1 minute, and your live portfolio URL will be ready to share with your instructor!
